# Precision Wave Co Website

Professional single-page website for **Precision Wave Co** – Pressure Washing, Landscaping & Handyman services in Los Angeles, CA.

## What’s Included
- Modern responsive design
- Your logo
- Services section
- **Our Work** photo gallery (real before/after jobs)
- **Reviews** section (selected from your 401 five-star reviews)
- Contact form + click-to-call
- Links to Instagram, Facebook, and Yelp
- Local SEO schema markup

## Files
- `index.html` – Main page
- `css/styles.css` – All styles
- `js/main.js` – Mobile menu + form handling
- `images/logo.png` – Your logo
- `images/gallery/` – Job photos

## Quick Deploy (Free & Fast)

### Option 1: Netlify Drop (Easiest – 2 minutes)
1. Go to https://app.netlify.com/drop
2. Drag the entire `precision-wave-co` folder onto the page
3. Your site goes live instantly
4. Click “Domain settings” → Add custom domain → enter `precisionwaveco.com`
5. Follow the DNS instructions from your domain registrar

### Option 2: Vercel
1. Go to https://vercel.com → New Project
2. Upload the folder or connect a GitHub repo
3. Deploy → add custom domain `precisionwaveco.com`

### Option 3: GitHub Pages
1. Create a new GitHub repo
2. Upload these files
3. Settings → Pages → Deploy from main branch

## After Going Live
1. Point precisionwaveco.com to the new host (update DNS)
2. Claim / update your Google Business Profile and link the website
3. Make sure Yelp, Instagram, and Facebook also link back to the new site
4. Consider running local Google Ads or Meta Ads targeting “pressure washing Los Angeles”, “power washing near me”, etc.
